# NATOフォネティックアルファベットフラッシュカード

NATO フォネティックアルファベット 26 文字を正方向・逆方向の両モードで学習するフラッシュカードアプリ。

## 機能
- NATO 26 文字（Alpha〜Zulu）のフラッシュカード
- 正方向モード：A → Alpha を答える
- 逆方向モード：Alpha → A を答える
- 発音（ICAO 発音ガイド）を表示
- 正解率・streak のリアルタイム表示
- 7×4 進捗グリッド（緑=正解/赤=不正解）
- 参照テーブル（全26文字の一覧）
- シャッフル機能
- 結果を localStorage に保存

## NATO 26文字
A=Alpha, B=Bravo, C=Charlie, D=Delta, E=Echo, F=Foxtrot, G=Golf, H=Hotel, I=India, J=Juliet, K=Kilo, L=Lima, M=Mike, N=November, O=Oscar, P=Papa, Q=Quebec, R=Romeo, S=Sierra, T=Tango, U=Uniform, V=Victor, W=Whiskey, X=X-ray, Y=Yankee, Z=Zulu
